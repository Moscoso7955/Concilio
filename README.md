# Callidus Co. Coming Soon

Static coming soon page for Callidus Co.

## Live Site

- https://callidusco.com
- https://www.callidusco.com

## Project Structure

- `index.html` contains the page markup, metadata, and styles.
- `assets/images/` contains the logo, background image, and Open Graph preview image.
- `assets/icons/` contains favicon and app icon files.
- `site.webmanifest` defines install/icon metadata for browsers.

## Editing

Edit `index.html` for copy, SEO metadata, and styling changes.

Image paths are absolute from the site root, such as `/assets/images/bg.jpg`.

## Deployment

This site is hosted on Vercel. Once the GitHub repository is connected to the Vercel project, pushes to the production branch will trigger new deployments through Vercel.
